# PyDM

بديل خفيف لـ IDM: تحميل متعدد الأجزاء مع استئناف، وإضافة متصفح تلتقط التحميلات.
لا يحتاج صلاحيات المدير ولا تثبيتاً.

## الحصول على البرنامج
1. ادفع المستودع إلى GitHub (يبدأ البناء تلقائياً).
2. من تبويب **Actions** ← آخر تشغيل ← **Artifacts** ← حمّل `PyDM`.
   - أو أنشئ وسماً `v1.0` فيظهر الملفان في **Releases**.
3. شغّل `PyDM.exe` مباشرة (بدون بايثون).

## الإضافة
فك `PyDM-extension.zip` ثم من `edge://extensions` أو `chrome://extensions`:
فعّل وضع المطور ← تحميل إضافة غير مضغوطة ← اختر المجلد.

## التشغيل من المصدر
`python pydm.py` (يحتاج بايثون مع tkinter).
